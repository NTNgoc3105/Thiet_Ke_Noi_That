## 4. Cách chạy dự án (Local)
Dự án sử dụng HTML5, CSS (Tailwind) và Javascript thuần. Để chạy trên máy tính cá nhân, vui lòng làm theo các bước sau:

1. Mở terminal tại thư mục chứa mã nguồn.
2. Chạy lệnh cài đặt các gói phụ thuộc (bao gồm Tailwind CSS):
   ```bash
   npm install
   ```
3. Khởi chạy dự án:
   ```bash
   npm run dev
   ```
